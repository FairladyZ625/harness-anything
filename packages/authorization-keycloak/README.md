# @harness-anything/authorization-keycloak

Keycloak-backed authorization, managed RBAC, and OIDC session adapters for
Harness Anything.

This package is consumed by `@harness-anything/daemon`. Its public entry points
are the package root and the named subpaths declared in `publishConfig.exports`;
the published tarball contains the compiled `dist` output.
