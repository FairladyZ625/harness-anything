# Deliverable Brief

## Deliverable Scope

Define the exact deliverable type (`proposal`, `report`, `specification`, `briefing`, `checklist`, or `other`), core questions answered, and explicit exclusions.

## Audience and Format

Identify the primary decision-makers or consumers, required sections, and expected artifact path under `artifacts/`.

## Upstream Baselines

Record each upstream input reference and its SHA-256 baseline digest mirrored into `artifacts/upstream-freshness.json` when using `upstream-fresh`.

## Review Checklist

- Deliverable manifest (`artifacts/deliverable-manifest.json`) matches the submitted deliverable SHA-256.
- All declared required sections are present and populated with substantive content.
- Claims are backed by verifiable sources or explicitly marked unverified.
