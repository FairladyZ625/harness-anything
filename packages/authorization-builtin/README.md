# @harness-anything/authorization-builtin

Single-machine built-in authorization, RBAC, and local session adapters for
Harness Anything. It is the default provider for a local installation and does
not require Keycloak, Java, or PostgreSQL.

For teams, multiple accounts, node joins, remote GUI access, or other
collaboration features, install and select the Keycloak provider described in
`docs-release/builtin-identity-provider.md`.
