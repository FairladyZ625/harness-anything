# 安装并加入边缘节点

受邀加入一个中心只需要两步：安装桌面 App，再用邀请链接完成加入。全程使用 GUI，不需要命令行；源码安装与 `ha edge join` 命令保留为备选，见文末。

## 1. 安装桌面 App

从 [GitHub Releases](https://github.com/FairladyZ625/harness-anything/releases) 下载安装包：

- macOS（Apple Silicon）：已签名并公证的 `dmg` 或 `zip`。打开 `dmg`，把 **Harness Anything** 拖进「应用程序」。
- Windows：x64 NSIS 安装器，首次运行可能出现 SmartScreen 提示。
- Linux：x64 AppImage 或 deb。

App 自带运行时，不需要另装 Node.js 或 Git。更多安装细节见[安装](01-install.md)。

在 macOS 上，如果直接运行了还没有拖进「应用程序」的 App，它会弹窗询问是否移动到「应用程序」目录：点 **移动到「应用程序」** 即可自动完成移动；选 **以后再说** 也能继续使用，但建议放入「应用程序」。

## 2. 管理员：签发一次性邀请

在中心 GUI 打开「设置 → 仓库与连接」，点页顶「邀请成员」入口的 **邀请成员加入** 按钮，直接进入邀请面板：

1. 在「成员」中选择已有成员，或选「新成员…」并填写用户名、邮箱与显示名称；可再填「边缘节点名称（可选）」。
2. 勾选要授予的「仓库」与「权限组」。
3. 点 **签发邀请**。一次性链接只显示一次：点 **复制链接**，通过独立渠道（如聊天软件、邮件）发给对方；点 **完成** 后链接无法再取出。

若本机还不能作为中心（登录服务证书未配置），入口不会隐藏邀请，而是先提示缺的那一步：点 **去配置登录服务** 配好证书，再回到页顶「邀请成员」入口签发邀请。

邀请有效期为 72 小时，只能消费一次。「邀请审计」列表显示每条邀请的状态（待消费 / 已消费 / 已过期 / 已撤销），待消费的邀请可以点 **撤销** 作废。不要公开发布邀请链接。

### 配置边缘节点可访问的地址

在「设置 → 仓库与连接 → 中心节点」分别配置中心服务地址和登录服务地址。中心服务地址填写完整的 HTTPS origin（例如 `https://center.example.com:7545`）；登录服务地址由登录服务证书设置中的 hostname 与 port 决定。两者可以使用不同的域名和端口。它们是邀请中给客户端使用的地址，与 daemon/Keycloak 的监听地址分开；中心 TLS 证书的 SAN 必须覆盖中心服务地址的主机名，登录证书必须覆盖登录 hostname。登录 hostname 同时是 Keycloak issuer；更改后，已有登录会话需要重新认证。

两个地址都必须能从边缘节点所在网络解析并连通，包括正确的 DNS、路由、防火墙规则和 NAT 端口映射。设置时中心会尝试探测中心服务地址，但内网回环 NAT 可能让探测误报；加入向导会在登录前分别检查中心与登录服务，并指出失败的一端。产品不提供中继；没有端口映射时，公网地址仍然不可达。

中心只有内网地址时，可以先在边缘机器上建立 SSH 本地转发。邀请里的主机名必须在该机器上指向本地转发监听地址，并且登录证书仍需信任：

```bash
ssh -N \
  -L <邀请中的中心主机>:<中心端口>:<中心内网主机>:<中心端口> \
  -L <邀请中的登录主机>:<登录端口>:<登录服务内网主机>:<登录端口> \
  <跳板登录>
```

若邀请中的主机名不是边缘机器已有的本地地址，需要先用本机回环别名或本地 DNS/hosts 映射让它指向 SSH 本地监听地址。转发端口必须与邀请中的 URL 一致。

## 3. 成员：打开邀请链接加入

两种方式任选：

- 直接点邀请消息里的 `harness-edge://join/…` 链接，App 会自动打开并预填链接；或
- 打开 App，在首页（还没有项目时的空状态）或左上角项目切换器里点 **加入中心**，把邀请链接粘贴进「邀请链接」输入框。

点 **开始加入**。链接只在本机使用，不会被上传或记录；邀请链接已包含所需的信任信息，无需手工配置。

## 4. 浏览器设备登录

向导显示「登录网址」与「验证码」：

1. 点 **在浏览器打开**（或手动打开该网址），在浏览器里输入验证码并批准登录；**复制验证码** 可一键复制。
2. 等待期间 App 显示「等待批准…」，批准后自动继续，不需要手动刷新；**取消登录** 可返回上一步。

登录服务暂时不可达时 App 会提示并自动重试。

## 5. 首次同步

App 为邀请的每个仓库依次显示：准备工作区 → 注册仓库 → 首次同步中 → 已同步。完成后显示「加入完成，已切换到第一个加入的仓库。」；个别仓库失败时显示「部分仓库未同步成功，可稍后重试或联系邀请人。」，失败仓库会在列表里给出原因。

## 6. 出错了怎么办

向导会把失败原因和下一步一起显示。常见情形对照：

| App 显示                                       | 怎么办                                                               |
| ---------------------------------------------- | -------------------------------------------------------------------- |
| 邀请链接无效或已损坏。                         | 请向邀请人重新获取链接后再试。                                       |
| 邀请已过期。                                   | 请邀请人重新签发一份邀请。                                           |
| 邀请已被使用，一次性链接不能重复加入。         | 请邀请人重新签发一份邀请。                                           |
| 邀请已被撤销。                                 | 请邀请人重新签发一份邀请。                                           |
| 中心的证书指纹与邀请链接不符，连接可能被冒用。 | 确认链接来自受信任的管理员；若中心证书确实更换过，请邀请人重新签发。 |
| 当前登录的账号与邀请指定的人不一致。           | 按邀请指定的账号完成登录，或请邀请人改签给你实际使用的账号。         |
| 邀请签发时的权限已发生变化。                   | 请邀请人按最新权限重新签发。                                         |
| 本机版本与中心不一致，中心拒绝了握手。         | 把 App 升级到与中心相同的版本后再试。                                |
| 设备登录超时，尚未完成批准。                   | 重新开始加入，并在有效时间内完成浏览器登录。                         |
| 登录服务暂时不可达。                           | 检查网络后重试；若持续失败请联系中心管理员。                         |
| 登录服务拒绝了本次设备登录。                   | 重新开始加入；若持续失败请联系中心管理员。                           |
| 加入没有完成，中心或登录服务返回了错误。       | App 会一并显示中心返回的原始说明；按说明处理或联系邀请人。           |

## 备选：源码安装与命令行加入

在没有 App 安装包的机器上，可以先做源码安装，再用命令行加入。在干净的 macOS 或 Linux 机器上准备 Git、Node.js 24+ 与 curl，再运行源码安装命令：

```bash
git --version
node --version  # 必须为 v24 或更高版本
curl --version
```

```bash
curl -fsSL https://raw.githubusercontent.com/FairladyZ625/harness-anything/main/scripts/install-source.sh | bash
```

安装器把源码保存在 `~/.local/share/harness-anything`，执行 `npm ci`，构建 daemon、CLI 与 Electron GUI，并通过
`npm link` 生成 `ha` 入口。Linux 会设置 Electron 所需的 `chrome-sandbox` 属主与 setuid 权限（必要时使用
`sudo`）。

受邀成员运行：

```bash
ha edge join '<邀请链接>' [--root <目录>] [--quota-bytes <字节数>]
```

命令会完成设备登录，消费邀请，并完成每个所选仓库的首次同步。机器凭据只写入本机边缘配置；加入回执与状态查询不返回凭据。如果所选仓库或权限组快照已改变，
中心会拒绝加入，需要由邀请人按最新权限重新签发。

省略 `--quota-bytes` 时，加入命令按每个目标目录所在卷的可用空间推导副本配额；指定后会把该持久配额用于首次同步。若中心快照超过可用或指定配额，加入会立即失败并显示同步原因。已加入的节点可用下面的既有命令调整配额并重试同步：

```bash
ha daemon fleet edge sync --quota-bytes <字节数>
```

Wayland 会话启动 GUI 时使用 `ELECTRON_OZONE_PLATFORM_HINT=auto ha gui`。加入后可运行
`ha gui --root <边缘仓库>` 查看中心台账，再从该仓库使用通常的 `ha runtime run` 派出 Agent。
